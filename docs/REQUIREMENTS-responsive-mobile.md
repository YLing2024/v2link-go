## 1. 实测到的问题（必须逐条修掉，并给出前后对照数字）

以 390×844 实测（真实界面、有数据）：

| 项 | 实测 | 目标 |
|---|---|---|
| 表格 | 2 张（8 列）在 390px 下超屏，**表体本身可横滑（`.ant-table-body`，最大可滚 916px）—— 这点是好的，不是缺陷**（注意别把 antd 的表头克隆 `.ant-table-header` 当缺陷，它天生 `overflow:hidden`） | 保持可横滑；顺带确认每张都带 `scroll={{x:'max-content'}}`、祖先无 `overflow:hidden` 裁切 |
| 触摸目标 | 31 个控件 **31/31 < 40px**（8 个 < 32px） | 主要操作 ≥44px、次要图标 ≥32×32、**表单输入框/选择器 ≥44px**、间距 ≥8px |
| 字号 | **33 处可见文本 < 12px** | 可见文本 ≥12px（正文 13–14px） |
| 文档级横向溢出 | 0 ✅（保持） | 仍为 0 |

## 2. 要做的

1. **表格**：全仓 `Table` 排查 → 补 `scroll={{ x: 'max-content' }}`；确认没有祖先 `overflow:hidden`/固定宽容器把右侧裁掉；操作列在窄屏不换行错位。
2. **触摸目标**：`@media (pointer: coarse)` 与窄屏断点下放大（`min-height`、命中区内边距），**桌面尺寸不变**；图标按钮（如刷新/关闭/复制）撑到 ≥32×32。
3. **字号**：把所有 <12px 的可见文本提到 ≥12px（次要说明 12px、正文 13px 起）。
4. **工具栏/筛选区**：窄屏允许换行或折叠，不许挤压到出现横向滚动条。
5. **窄屏导航**：不得隐藏导航（用户明确偏好），用抽屉/折叠菜单呈现。
